# 김재원 팬미팅 연습게임

팬미팅(싸인회)을 앞두고 3일 동안 연습하는 리듬게임. 웹 브라우저에서 바로 실행되는 팬게임.

키보드 + 마우스로 하는 PC 게임. 시청자가 책상 앞에 서면 **신호음 다음 박자**에 맞는 동작을 해준다.

동작마다 조작이 정해져 있다. 손으로 하는 일은 마우스, 몸으로 하는 일은 스페이스.

| 시청자 | 신호음 | 해줄 것 | 조작 |
| --- | --- | --- | --- |
| 종이 든 시청자 | 띵 | 싸인 | 마우스 클릭 |
| 악질 시청자 | 뿌- | 밴 | 마우스 누른 채 옆으로 휙 (← → 키도 가능) |
| 폰 든 시청자 | 삐삐 | 찰칵찰칵 | 스페이스 2번 |
| 늑대인간 시청자 | 아우~ | 같이 아우우우 | 스페이스 꾹 (2박) |

다른 조작을 쓰면 삑. (종이에 스페이스 = "사진 말고 싸인!", 폰에 클릭 = "폰에 싸인을 해버렸다")

날이 갈수록 곡이 빨라진다. 1일차 104 BPM → 2일차 120 → 3일차 136.

- 1일차: 종이, 악질 (마우스만)
- 2일차: + 폰 (스페이스 등장)
- 3일차: + 늑대인간 (스페이스 꾹)

전역하고 첫 팬미팅을 앞두고, 군대에서 굳은 몸을 3일 동안 푸는 이야기.

각 날짜는 스토리 → 연습(튜토리얼) → 본게임 → 결과 순서. 본게임에서 55점 이상이면 다음 날이 열린다. 연습은 동작마다 2번씩 성공하면 끝나고, 한 번 끝낸 날은 다시 할 때 연습을 건너뛴다.

3일차까지 통과하면 엔딩. 3일 내내 야호한 재원이 몸살이 나서, 다음 날 아침 네이퍼 팬카페 방송공지에 휴방 공지를 올린다.

일시정지는 `Esc` 또는 `P`. 스토리는 클릭이나 스페이스로 넘긴다. 화면은 창 크기에 맞춰 가로로 꽉 찬다.

## 실행

빌드 없음. 정적 파일만 있으면 된다.

```bash
npx serve .
```

또는 `index.html`을 브라우저로 그냥 열어도 된다.

GitHub Pages로 올리려면 저장소 Settings → Pages → Branch를 `main` / `(root)`로 지정.

## 구조

```
index.html      화면 뼈대
css/style.css   버튼, 대화창, 결과 카드
js/data.js      채보, 스토리, 문구, 곡 설정, 엔딩 팬카페 글 (D.cafe)
js/audio.js     소리 (전부 Web Audio 합성, 음원 파일 없음)
js/art.js       그림 (전부 캔버스에 직접 그림, 이미지 파일 없음)
js/game.js      판정, 입력, 진행
fonts/          Jua, Gaegu (SIL Open Font License 1.1)
```

채보는 `js/data.js`의 `D.charts`에서 고친다. `P` 종이, `T` 악질, `C` 폰, `W` 늑대인간(2칸), `-` 쉬는 칸.

## 판정

- 완벽: ±약 65ms, 굿: ±약 130ms (빠른 곡에서는 조금 더 좁아진다)
- 신호음이 나온 뒤 너무 일찍 누르면 삑
- 블루투스 이어폰처럼 소리가 늦게 들리는 환경은 설정의 "판정 보정"으로 맞춘다

## 점검용 주소

- `?day=2` : 2일차 본게임으로 바로 시작
- `?day=3&mode=tutorial` : 3일차 연습부터
- `?auto=1&day=1` : 자동 플레이
- `?story=ending` : 엔딩 컷씬 바로 보기
